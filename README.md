# 三国霸业 · 网页复刻版

> 复刻步步高电子词典经典游戏《三国霸业》——内政经营 + 外交谋略 + 战棋攻城 + 武将单挑，跑在浏览器里。

## 快速开始

```bash
# 方式一：直接打开（推荐）
双击 sanguo-baye/phaser/index.html

# 方式二：本地服务（想跑 E2E 时用）
cd sanguo-baye/phaser && python -m http.server 8157
# 浏览器打开 http://localhost:8157/index.html
```

运行测试：

```bash
cd sanguo-baye/phaser
node smoke.js        # 逻辑冒烟：60 月内政 + 30 日战棋
node strat-test.js   # 计谋与状态异常专项（20 项）
node duel-test.js    # 单挑专项 + 100 场战斗节奏模拟
node e2e.js          # Playwright 端到端（需先起服务，会产出 shots/ 截图）
```

## 技术选型

- **Phaser 3.80.1**（vendored，离线可跑）
- **零构建**：纯 `<script>` 顺序加载，没有 bundler / 没有 npm 运行时依赖
- **程序化美术**：地形、单位、武将头像全部由 `js/art.js` 代码绘制，无图片素材
- **WebAudio 合成音效**：无音频文件
- **规则层与表现层分离**：`js/core.js` 是不依赖 Phaser/DOM 的纯逻辑，可在 node 里直接测试
