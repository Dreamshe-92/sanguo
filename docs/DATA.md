# docs/DATA.md — 数据字典

> `sanguo-baye/phaser/js/data.js` 中所有全局数据表的字段说明。
> **改动任何一张表，都要同步更新本文件。**

---

## 全局尺度

| 常量 | 值 | 说明 |
|------|----|----|
| `LW` / `LH` | 1152 / 720 | 逻辑画布尺寸 |
| `RENDER_SCALE` | 2 | 实际画布 = 2304×1440，相机 zoom=2 |
| `Core.BW` / `Core.BH` | 17 / 11 | 战场网格宽高 |

## 工具函数（data.js 末尾）

`rand(n)` 随机整数 / `rnd(a,b)` 浮点区间 / `pick(arr)` 随机取一 / `clamp(v,a,b)` 夹取 / `hash32(s)` 字符串哈希（用于程序化头像种子）/ `facColor(i)` 势力配色。

## TROOP — 兵种（6 种）

| 键 | 名称 | mp | range | atk | def | 特性 |
|----|------|----|-------|-----|-----|------|
| `步` | 步兵 | 3 | 1 | 1.00 | 1.15 | 泛用，山地/森林无惩罚 |
| `弓` | 弓兵 | 3 | 2 | 1.10 | 0.90 | 远程 2 格，脆 |
| `骑` | 骑兵 | 4 | 1 | 1.20 | 0.80 | 机动强，山地/森林受限 |
| `水` | 水兵 | 4 | 1 | 0.90 | 1.00 | 河流无阻碍，陆地迟钝 |
| `极` | 极兵 | 5 | 1 | 1.45 | 1.20 | 需铁骑兵符，全能 |
| `玄` | 玄兵 | 2 | 1 | 0.75 | 1.05 | 需太玄兵符，可改天气 |

`cost:{plain,grass,mount,forest,river,base}` = 各地形移动力消耗。

## TERRAIN — 地形（8 种，数组索引即 tile 值）

| id | 名称 | defMod | 不利兵种 | 说明 |
|----|------|--------|----------|------|
| 0 | 平原 | 0.00 | — | 基准地形 |
| 1 | 草原 | 0.00 | — | 视野开阔 |
| 2 | 山地 | 0.30 | 步/弓 | `mAtk 0.4 / mDef -0.7` |
| 3 | 森林 | 0.15 | 步/弓 | `mAtk 0.5 / mDef -0.6` |
| 4 | 河流 | 0.00 | 水 | `mAtk 0.5 / mDef -0.5` |
| 5 | 村庄 | 0.10 | — | 补给点 |
| 6 | 营寨 | 0.20 | — | 守方增益 |
| 7 | 城池 | 0.38 | — | 攻城目标，减伤最强 |

`defMod` 直接作为 `(1 - defMod)` 的伤害减免系数。`bad` 中的兵种在此地形上攻击/防御受 `mAtk/mDef` 惩罚。

## WEATHER — 天气（5 种）

`晴 / 阴 / 雨 / 大风 / 冰雹`，`WEATHER_FX` 提供 `tint`（画面染色）与 `icon`。
计谋伤害天气系数：`晴 1.1 / 阴 0.95 / 雨 0.8 / 大风 1.0 / 冰雹 0.5`。

## ITEMS — 道具（32 件）

三类：`{t:"武", v:武力加成}`、`{t:"智", v:智力加成}`、`{t:"移", v:移动力加成}`、`{t:"符", v:解锁兵种}`。
生效方式：`Core.genItemBonus(g)` 聚合武将 `g.items` 上所有加成；`Core.gForce/gIntel` 已是"基础值 + 装备加成"。

## CITIES / CITY — 城池（38 座）

```
CITIES[i] = [id, 名称, x, y, [邻接城 id...]]
CITY[id]  = { id, n, x, y, adj }      // 运行时一律查 CITY
```
- `x/y` 为大地图坐标（逻辑画布 1152×720 坐标系）
- `adj` 为**地理推测生成，未经原版逐条校对**（见 PROGRESS.md 已知问题）

## STRATAGEM — 计谋（29 项）

通用字段：

| 字段 | 含义 |
|------|------|
| `lv` | 习得等级门槛 |
| `mp` | 技力消耗（对应单位 `u.hp`） |
| `rng` | 施放射程（0 = 自身/布设） |
| `dmg` | 基础伤害（经智力与天气修正） |
| `heal` | 治疗量 |
| `status` | `[状态名, 持续回合]`，如 `["混乱", 2]` |
| `trap` | 布设物 `{dmg, status, cross}`，有此字段即为布设类计谋 |
| `buff` | 增益，如 `{mv:3}` |
| `weather` | `true` 表示可改变天气（玄兵专属「天变」） |
| `intel` | `true` 表示侦察类（「谍报」） |
| `vs` | 兵种克制倍率，如 `{"步":1.5}` |
| `troop` | 限定兵种白名单 |
| `needTerrain` | 限定地形 id 数组（2=山地 3=森林 4=河流） |
| `needRiver` | 需靠近河流 |
| `needWeather` | 限定天气数组 |
| `banWeather` | 禁用天气数组（如火系怕雨） |
| `target` | `"self"` 自身 / `"ally"` 友军 / 缺省为敌军 |
| `desc` | 说明文本 |

分组：骑兵突击（践踏/冲锋/突击/突袭）、弓箭（飞矢/箭雨/火箭）、火攻（火攻/烈火）、地势（滚木/落石）、水系（水淹/海啸/撞击）、状态（咒封/定身/流言/天籁）、布设（陷阱/石阵）、支援（援兵/援军）、自身特殊（奋战/围攻/急行/奇门遁甲/潜踪/天变/谍报）。

## DUEL — 单挑

```js
DUEL = { maxRound: 6, acts: [ {k, name, desc}, ... ] }
```
四种行动：`攻`（强攻，中等伤害）/ `杀`（必杀，高伤但可能被看破）/ `守`（守备，减伤 55% 并回气）/ `退`（脱身，损兵约 12% 结束）。

## STATUS — 状态异常（6 种）

| 名称 | icon | 效果 |
|------|------|------|
| 混乱 | 乱 | 45% 概率行动失控 |
| 禁咒 | 咒 | 无法施展计谋 |
| 定身 | 定 | 无法移动（`reach()` 返回空） |
| 燃烧 | 燃 | 每回合持续掉兵 |
| 奇门 | 门 | 无视阻挡穿行 |
| 潜踪 | 隐 | 敌军无法发现 |

每种含 `icon`（战场血条旁色块字）与 `css`（配色）。

## SCENARIOS — 剧本（4 个）

```
{ name, year, month, years, desc, factions, fix, wild, items }
```
- `factions[]`：`{lord, cities, gens}`，由 `F(lord, cities, gens)` 构造
- `gens[]` 条目：`[名, 武力, 智力, 兵种, 等级]`
- 4 剧本：**董卓弄权 / 曹操崛起 / 赤壁之战 / 三国鼎立**
- 剧本 0 含 16 个势力；四剧本武将条目合计 194（跨剧本重复计）

## SUPP_GENS — 在野武将（88 名）

搜索指令可登用的补充武将池，不隶属于任何剧本势力。

## PAL / PAL_CSS / FAC_COLORS — 配色

`PAL` 提供常用色键（`gold/green/red/...`）；`FAC_COLORS` 为 8+ 势力循环配色，`facColor(i)` 按索引取色。
